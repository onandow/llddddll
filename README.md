#### 轻量级的纯前端网页随机抽取工具，支持自定义词条、权重设置及语音播报。

#### 主要功能 
* **自定义配置**：支持添加、修改、删除词条，可独立设置各词条权重及全局触发概率。 
* **防重复机制**：自动记录并排除最近 10 次抽取的结果。 
* **语音播报**：抽取结果后自动调用浏览器接口进行语音朗读。 
* **数据管理**：支持一键清空列表，支持通过文本或 JSON 文件导入/导出配置。
* **本地存储**：设置和词条自动保存在浏览器本地，会跟随缓存清空而消失。
* **镜像页面**：增加了镜像网页的按键。
#### 使用方法
1. 访问 bananaprince.icu/random
2. 点击右上角⚙️进入设置，添加词条并保存。 
3. 点击随一下。
